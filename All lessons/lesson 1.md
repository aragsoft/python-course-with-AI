# What is Python?

Python is one of the world's most popular programming languages.

It is:

- Easy to learn
- Easy to read
- Powerful
- Fast to develop with
- Used by beginners and professionals

Python was created by Guido van Rossum and released in 1991.

# Understanding print()

print() displays information on the screen.

Example

```python
print("Welcome")
print("Python")
print(100)
```

Output

```
Welcome
Python
100
```

---

# Comments

Comments are ignored by Python.

Example

```python
# This is a comment

print("Hello")
```

Use comments to explain your code.

---

# Common Mistakes

Wrong

```python
Print("Hello")
```

Correct

```python
print("Hello")
```

Wrong

```python
print(Hello)
```

Correct

```python
print("Hello")
```
